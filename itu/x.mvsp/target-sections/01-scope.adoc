
== Scope
//<Mandatory>

Minimum Viable Secure Product (MVSP) defines a baseline security level applicable to any organization developing or procuring enterprise software. The baseline's scope includes business controls, secure application design, implementation, and operation. As the controls are aimed to reach the minimum viable security level, it is not a replacement for comprehensive security frameworks. MVSP's simpicity however enables its efficient usage for vendor selection, self-assessment, SDLC, and contractual controls withouth heavy resource investments.
