== Summary
// <Mandatory>

In this recommendation, we cover Minimum Viable Secure Product (MVSP), a list of essential application security controls. The control groups include business, application design, implementation, and operational controls. In clause 6 the draft recommendation is included with control descriptions and Annex A provides a reasoning for each contro detailing what the control measures and why it should be included. The recommenadtion also addresses the formal requirements, including definitions, abbreviations, terms used.
